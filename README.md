# Cardiovascular Disease Prediction Using Machine Learning

## Project Overview
MSc IT with Data Analytics — Dissertation Project
University of the West of Scotland, 2025-26

## Setup Instructions
1. Clone or download this repository
2. Create virtual environment: `python -m venv .venv`
3. Activate: `.venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`
5. Open notebooks in order: 01_preprocessing → 02_ml_modelling

## Dataset
Cardiovascular Disease Dataset — Kaggle (Sulianova, 2019)
70,000 patient records, 12 features + 1 target variable
